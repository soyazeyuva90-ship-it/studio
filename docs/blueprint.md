# **App Name**: OOBy

## Core Features:

- Design Project Architect: An AI-powered tool that acts as a collaborative partner, using project descriptions to suggest specific 2026 design trends and layout configurations for new client requests.
- Immersive Project Hub: A centralized dashboard where clients can submit website design requests, upload brand assets, and track their proposal status.
- Interactive Trend Gallery: A 3D-enabled showcase section using scroll-triggered animations to demonstrate current design innovations like WebGL models.
- Service Quote Engine: A dynamic calculator that estimates project timelines and costs based on the complexity of chosen immersive features.
- Request Persistence Layer: Integration with a backend database to securely store client information, project requirements, and interaction history.

## Style Guidelines:

- Primary Color: Electric Indigo (#8B5CF6) - a vibrant, high-saturation purple that represents the boundary between art and tech.
- Background Color: Obsidian Void (#110E1B) - a deep, dark violet-tinted black that provides maximum contrast for 3D elements.
- Accent Color: Azure Flux (#6088FA) - a bright blue-violet hue shifted 30 degrees for high-impact CTA buttons and status indicators.
- Font pairing: 'Space Grotesk' (sans-serif) for tech-forward headlines and 'Inter' (sans-serif) for high-readability body copy across all interfaces.
- Ultra-thin line icons with glowing neon effects, inspired by futuristic schematics and HUD interfaces.
- A wide-screen bento-box grid with asymmetric modules that creates a sense of organic movement during scrolling.
- Kinetic typography and slow-motion Z-axis parallax effects on hero sections to create a deep immersive feeling.
